# Oktave H1 (concept by Anorix)

Oktave H1 is a concept product site for a premium audio device, with a real-time morphing 3D product and scroll-driven storytelling. Product, specs and prices are fictional.

Built with Next.js, Tailwind CSS, three.js / React Three Fiber, GSAP ScrollTrigger and Lenis.

## Reference sites
- https://explore.solk.com/ (Awwwards SOTD, Jun 13 2025)

No code, copy, logos or images were taken from the reference. See CREDITS.md.

## Run
`npm install` then `npm run dev` (or `npm run build` + `npm start`).
